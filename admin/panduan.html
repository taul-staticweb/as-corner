Panduan Penggunaan Admin A's Corner

Selamat datang di panel admin A's Corner. Dokumen ini akan memandu Anda cara mengelola (menambah, mengedit, dan menghapus) konten website secara langsung melalui HP maupun laptop.

1. Cara Menambah Postingan Baru

  1. Gulir ke atas ke bagian "Tulis Postingan Baru" di halaman Dashboard.
  2. Pastikan form dalam keadaan kosong. Jika form sedang berisi data untuk diedit, klik tombol Batal Edit terlebih dahulu.
  3. Isi Kolom Data:
    • Tema / Kategori: Masukkan kategori tulisan, contoh: Quotes, Opini, atau Informasi.
    • Judul Tulisan: Masukkan judul postingan.
    • Isi Postingan: (Lihat Panduan Khusus Mengisi Kolom Isi di bawah).
    • URL Foto Utama: Masukkan URL langsung menuju foto untuk dijadikan Thumbnail.
    • URL Video / Link Eksternal: Opsional.
  4. Klik tombol Publikasikan.

2. Cara Mengedit & Menghapus Postingan

  • Edit: Gulir ke bagian "Daftar Postingan", cari judul tulisan, klik tombol Edit. Form akan otomatis terisi. Lakukan perubahan lalu klik Simpan Perubahan.
  • Hapus: Klik tombol Hapus warna merah, lalu konfirmasi OK.

3. Panduan Khusus Mengisi Kolom "Isi Postingan" (Rich Text)

Kolom "Isi Postingan" dilengkapi dengan editor visual. Anda bisa menebalkan teks, membuat poin, atau memasukkan gambar.

A. Memasukkan Gambar (Sangat Penting)

Untuk menjaga kecepatan website, sangat disarankan untuk menggunakan gambar yang ringan:

  • Gunakan format gambar .webp atau .svg (jika ilustrasi vektor).
  • Upload gambar Anda ke hosting gambar gratis seperti imgbb.
  • Setelah di-upload di imgbb atau layanan lain, salin URL langsung (Direct Link) dari gambar tersebut.
  • Di dalam editor tulisan, klik tombol Image (Gambar).
  • Sebuah popup akan muncul meminta link gambar. Paste link gambar Anda ke sana lalu tekan OK.
  • Gambar akan otomatis dimasukkan dan diatur berada di tengah artikel.

B. Tombol Editor

  • Arahkan dan tahan (hover) pada tombol-tombol di editor (seperti B, I) untuk melihat penjelasan fungsinya.
